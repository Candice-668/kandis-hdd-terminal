# Agent Ops 调度大屏

一个纯前端的 **AI 智能体调度可视化大屏**：12 个智能体并行处理 64 个任务，用一个旋转的"数据飞轮"把任务流、工作流和输出流实时画出来。单个 HTML 文件，无需构建、无需后端，双击就能打开，适合放在展厅、办公室电视或直播背景上。

提供两套主题，一键切换：纸面（白天）与夜间。

> 页面里的数字全部是**示例数据**，由内置的模拟引擎生成，不是真实指标。接入真实数据的方法见下文。

---

## 功能一览

### 主舞台（数据飞轮）

- **左侧：汇聚连线**
  - 几百条细线交织成网，汇聚到三个"工作流节点"上，节点上有亮点沿线流入。
  - 节点标签每 2.4 秒切换一次：文字先乱码跳动、再定格成新的工作流名，同时有一圈波纹扩散、一股亮点冲进节点。
  - 鼠标指向节点，会显示该工作流的来源数、运行中的任务数和质检分。
- **中间：旋转环带**
  - 环带里排着两列执行记录（代码片段、耗时表、数字矩阵、条码块），沿半径方向排布，跟着飞轮一起转。
  - 代码块里"正在执行"的那一行会反白高亮。
  - 外弧上的刻度和字节标签也一起转。
- **右侧：外射谱线**
  - 上千条细线从外环向外放射，随飞轮旋转。部分扇区是亮带（夜间为荧光绿）。
  - 谱线上有亮段向外滑动。
- **齿环与扫光**
  - 外环外侧有一圈反向快转的齿环，内侧有一圈反向慢转的虚线环。
  - 每隔约 7 秒，有一道光束扫过整个飞轮。
- **右下角浮层**
  - 稳定性检查：CFL 数值，来自下方粒子求解器的实时流速。
  - 质检状态：已匹配 / 待复核。

### 顶部指标（左上角透明浮层）

- 标题、实时时钟。
- 6 个指标：任务、运行中智能体、工作流、产出、已匹配、待复核。
- 指标下方的高亮下划线每 4.5 秒轮换一次。

### 底部四个面板

| 面板 | 内容 |
|---|---|
| TASK FEED 任务流 | 滚动日志，显示智能体读取 / 生成 / 核验 / 复核任务的记录 |
| ADVECTION / PARTICLE SOLVER 粒子求解 | 粒子流场动画：点击画面加入涡流；ADVECT / PROJECT 切换两种流动模式；RERUN 重置 |
| WORKSPACE 执行代码 | 9 套不同的示例代码逐字打出、轮流出现，一轮内不重复；右上角显示文件名和对应的智能体 |
| 12 AGENTS / DISPATCH 调度 | 12 个智能体当前在做的任务、阶段和进度条 |

### 交互

| 操作 | 效果 |
|---|---|
| 右上角「夜间 / 纸面」 | 切换主题（默认跟随系统深浅色） |
| 右上角「暂停 / 继续」或按空格键 | 暂停 / 继续所有动画 |
| 鼠标指向左侧三个节点 | 显示工作流详情 |
| 点击粒子面板，或聚焦后按 Enter | 加入一个涡流 |

### 其他

- **自适应**：宽屏一排 4 个面板；宽度 ≤1100px 时变成两列；手机竖屏单列。
- **夜间模式**额外有柔光和偶发的横向故障闪烁。
- 系统开启「减少动态效果」时，页面默认处于暂停状态。

## 快速开始

### 本地打开

直接双击 `index.html`，用 Chrome / Edge / Safari / Firefox 的较新版本打开即可。

也可以起一个本地静态服务器（任选其一）：

```bash
python3 -m http.server 8000
# 或
npx serve .
```

然后访问 `http://localhost:8000`。

### 部署到 GitHub Pages

1. 把仓库推到 GitHub。
2. 进入仓库的 Settings → Pages，Source 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`。
3. 稍等片刻，访问 `https://<你的用户名>.github.io/<仓库名>/`。

### 放到大屏上

在电脑或小主机上用浏览器打开页面，按 F11（Mac 为 Ctrl+Cmd+F）全屏即可。推荐 1920×1080 或更高分辨率。

## 自定义

所有可改的内容都集中在 `index.html` 里 `<script>` 的最前面。

### 1. 名称和内容：`CONFIG`

```js
const CONFIG = {
  agents:    [['01','检索'], ['02','拆解'], ...],    // 12 个智能体：编号 + 名称
  taskNames: ['竞品资料检索', '需求拆解', ...],       // 任务名称池
  workflows: ['资料检索', '需求拆解', ...],           // 11 个工作流（节点标签用）
  codeSets:  [                                        // 执行代码面板的示例代码
    {file: 'dispatch.py', agent: 1, start: 7, lines: ['# 每日调度…', '...']},
    ...
  ]
};
```

- `codeSets` 里每一组是一套代码：`file` 显示在面板右上角，`agent` 是对应智能体的序号（从 0 开始），`start` 是起始行号，`lines` 是代码行。想加新的就照格式多写一组。
- 环带里滚动的代码片段在 `CODEBITS` 数组里。

### 2. 动画速度

| 位置 | 作用 | 默认值 |
|---|---|---|
| `const SPIN = 0.16` | 飞轮转速（弧度/秒），越大越快 | 0.16 |
| `setInterval(... switchHub(), 2400)` | 节点标签切换间隔（毫秒） | 2400 |
| `setInterval(... step(), 900)` | 模拟数据刷新间隔（毫秒） | 900 |
| `setInterval(... typeTick(), 34)` | 代码打字速度（毫秒/字） | 34 |

### 3. 配色

颜色全部用 CSS 变量定义在 `<style>` 顶部：`:root` 是纸面主题，`[data-theme="dark"]` 和 `prefers-color-scheme: dark` 里是夜间主题。画布里的颜色也从这些变量读取。

| 变量 | 作用 |
|---|---|
| `--bg` `--panel` `--ink` `--mute` `--hair` | 页面底色、面板底色、文字、次要文字、细线 |
| `--c-line` | 画布连线、谱线的颜色 |
| `--c-hot` | 亮带、齿环颜色（夜间为荧光绿） |
| `--c-hi` | 高光颜色 |

## 接入真实数据

页面的数据来自 `<script>` 里「3. 模拟引擎」这一段。核心是三个数组：

- `tasks`：任务，字段为 `id` `name` `wf`（所属工作流）`state`（`queued` / `run` / `done`）`prog`（0–1 进度）`agent`
- `agents`：智能体，字段为 `code` `name` `task`（当前任务序号，空闲为 -1）
- `wfs`：工作流，字段为 `id` `name` `q`（质检分，≥0.8 视为已匹配）

`step()` 每 900 毫秒更新一次这三组数据，然后调用 `renderAll()` 刷新面板。

接真实数据时，把 `step()` 换成"从接口拉数据 → 写进这三个数组 → 调用 `renderAll()`"即可。例如：

```js
async function pull(){
  const res = await fetch('/api/agent-ops/state');   // 换成你自己的接口
  const data = await res.json();
  // 按上面的字段把 data 写进 tasks / agents / wfs
  renderAll();
}
setInterval(pull, 3000);
```

日志面板用 `log(verb, task)` 追加记录，`verb` 可选 `read` / `build` / `check` / `review`。

## 技术说明

- 纯原生 HTML + CSS + Canvas 2D，没有任何框架和构建步骤，单文件约 50 KB。
- 唯一的外部资源是 Google Fonts：JetBrains Mono、Noto Sans SC。
  - 加载不到时，会自动回退到系统等宽字体，功能不受影响。
  - 在中国大陆网络下如果加载慢，可以把字体下载到本地，改成本地 `@font-face` 引用。
- **性能**：静态图层（连线网、环带底板）预先画到离屏画布，每帧只重画会动的部分；谱线只画当前可见的扇区。夜间模式有额外的发光叠加，比纸面模式更吃性能。
- **兼容降级**：
  - 夜间柔光依赖 `CanvasRenderingContext2D.filter`，不支持的浏览器（如部分 Safari）会自动跳过。
  - 扫光依赖 `createConicGradient`，不支持时退化为纯色扇形。

### 代码结构（`index.html` 内的 `<script>`）

| 段落 | 内容 |
|---|---|
| 1. 数据配置 | `CONFIG`、`CODEBITS`、`SPIN` |
| 2. 工具 | 随机数、颜色、主题读取 |
| 3. 模拟引擎 | `tasks` / `agents` / `wfs` 与 `step()`（接真实数据时替换这里） |
| 4. DOM 面板 | 指标、任务流、调度、执行代码 |
| 5. 主舞台 | 飞轮的各个图层：连线、环带、谱线、齿环、扫光、节点标签 |
| 6. 粒子求解器 | 底部粒子面板 |
| 7. 主循环与控制 | 动画循环、暂停、主题切换、尺寸自适应 |
